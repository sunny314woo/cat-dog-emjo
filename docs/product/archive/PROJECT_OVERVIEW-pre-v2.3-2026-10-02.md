# EMJO · H5 首版需求与实施边界

更新日期：2026-10-02  
状态：核心范围已明确，可进入本地开发；接口占位、商业参数和生产环境核验在正式联调／上线前补齐。本文描述目标产品，不代表功能已经完成。

## 1. 首版目标与已确定决定

实现一个参考豆包草稿重新设计的响应式 HTML5 表情贴纸制作网站，移动端优先，也支持桌面浏览器。完整流程是：

**上传同一主体照片 → 确认／裁切主体 → 生成四风格预览 → 选择风格并补充要求 → 生成带保护标记的低清九宫格预览 → 支付 → 查看高清原图、下载完整图与九张切图、通过邮件领取。**

本轮已确定：

- 首发做 H5；小程序与 App 保留为后续选项，不纳入本轮交付。
- 沿 `doubao/萌宠九宫格表情包生成器.html` 的交互和 UI 方向重构；当前根目录英文展示站是待替换版本。
- 至少上传一张，允许同一个人或同一只动物的多张照片；每次处理一个指定主体。
- 图片生成由项目服务器调用火山 Seedream 5.0 Lite。密钥、模型／接入点等待提供的信息使用占位，普通用户不填写 API 配置。
- 基础商品按一个主体、一个风格、一页九宫格设计；基础模型输出两张主图：四风格图和九宫格图。
- 支付前只能看到受保护的低清结果；支付后开放同一份高清成果、完整图和切图下载，并发送交付邮件。
- 首版采用免注册购买，不建立密码、注册、登录或个人中心；仍需服务端订单与领取凭证。
- 免费用户每天可生成一套：一张四风格主图 + 一张九宫格主图；不按 IP 识别用户。免账号身份的识别方式见下文，全站预算另设。
- 每笔付费订单额外提供两次主图重做额度：完整重做一套消耗两次；只重做九宫格每次消耗一次，最多两次。
- 提供付款后 14 天内可申请退款的产品承诺；文件保留最多 30 天，使用 Resend 交付。
- 网站与支付入口使用 `wisteriasoftware.uk`，与 Outline 官网同域名；不再以旧 `pet.wisteriasoftware.uk` 作为新方案目标。
- 与同台服务器上的其他产品隔离。`services/account-server` 仅作为实现参考，不把新功能直接加入其中。

## 3. 上传、框选与生成合同

### 上传与主体范围

多张图片必须是同一主体。合照先明确一个目标，必要时裁出目标；不能把多图上传理解为双人或双宠互动。

当前 v0.5／AGENTS 明确的生成合同是 1–2 张同主体原照片。此前讨论过最多三张，但尚未确认。**本地首轮实现默认 1–2 张，上传上限配置化；扩展到三张时同步扩展图片职责与模板，并进行对照验证。** 该默认符合至少一张、允许多张的产品方向。

人物与动物共用流程，按现有模板选择分支；上线开放的种类以质量验证通过为准，不能把提示词支持写成已验证支持。

### 裁切交互默认方案

每张照片可拖动、缩放、重新调整和确认。默认正方形，提供 3:4 竖框、4:3 横框；已经清晰完整的单主体照片允许使用整图。保留耳朵、发顶、口鼻、关键花纹和需要的身体范围，不拉伸图片。

浏览器纠正方向、裁切并压缩后上传；最长边 2048px 为初始可调默认值，上传文件体积与像素限制由服务端再次校验。具体文件限制在移动端性能与还原质量测试后冻结。用户能看到实际发送的裁切结果。

### 提示词与两阶段生成

- 第一阶段：用户确认后的原照片 + 当前四种风格模块 → 一张四格风格图。
- 第二阶段：同样的原照片 + 从第一阶段裁出的所选风格图 + 当前九个动作 + 用户补充要求 → 一张九宫格。
- 明确每张图片的职责：原照片锁定身份，所选预览只控制画风；补充要求不能覆盖身份、主体数量和安全裁切约束。
- 风格库保留十三种候选；每次预览四种，默认组合可配置，最终上架组合在样例评审时确定。
- 9／18／27 张的模板能力保留。首个商业闭环先验收九张；18／27 套餐、价格和免费预览范围另行配置，不擅自删除现有模板。
- 不在请求失败后退化为无原照片生成并宣称成功。检查布局、单元数量、跨格、身份与透明效果；文件是 PNG 不等于具有合格 alpha。

## 4. 预览、支付与交付

### 预览与购买内容

服务端先生成高清九宫格，保存为私有文件，再制作逐格带水印／保护标记的低清版本。保护直接写入预览图像像素，不依赖网页遮罩。未付款客户端不能获得高清原图、模型原图 URL 或最终 ZIP。

预览保留足够的脸部与动作细节，便于判断是否像和是否值得购买。付款后解锁同一份成果，默认不重新生成，避免付费结果与预览不一致。

首版拟定交付包：高清完整九宫格 PNG、九张分别裁切的 PNG，以及汇总 ZIP。目标为合格透明边缘；需通过程序与样例检验后才能宣传透明交付。主图及单格尺寸作为配置，按每张实际输出检查，不把整张大图尺寸当成单格尺寸。

### 支付闭环

首版使用 Paddle（负责人本轮口述的 Pando 按本项目已有支付服务理解）。服务器根据商品配置创建订单与交易，绑定报价、金额、币种、生成任务和交付邮箱。

| 地区／商品 | 当前方案 | 状态 |
| --- | --- | --- |
| 美元定价的一页九宫格 | 暂按现有 US$9.99，保留改为 US$9.90／US$10 的配置能力 | 负责人已存在的价格；最终金额上线前确认 |
| 中国大陆定价的一页九宫格 | CNY ¥10.00 | 需在 Paddle 配置地区价格并联调 |
| 已提供价格 ID | `pri_01m3m6d7yd5hjn5wz071wkwcsy` | 负责人提供；所属环境、商品和实时金额待 API 联调核验 |

Paddle 支持同一价格对象设置国家级 `unit_price_overrides`，例如默认 USD 999 分、`CN` 覆盖为 CNY 1000 分，均关联同一商品。中国区暂按中国大陆 `CN` 理解，港澳台和其他国家不自动并入该定价。以结账国家和服务端获得的 Paddle 报价为准，语言切换不改变收费地区，页面不能只换货币符号。是否含税需在正式售价中说明。来源：[Paddle 价格字段](https://developer.paddle.com/api-reference/prices/get-price/)。

Paddle 支持 CNY，但可用支付方式另受账户、地区和币种影响；需要支付宝等方式时单独核对启用状态。公开费率为 5% + US$0.50／笔，低于 US$10 的产品官方建议联系确认定价。¥10 单价需将支付固定手续费、免费预览转化、重做和退款一并核算；本轮不直接变更线上价格。来源：[支持币种](https://developer.paddle.com/concepts/sell/supported-currencies/)、[Paddle 费率](https://www.paddle.com/pricing)。

支付完成必须经服务端验证回调、环境、交易、商品与金额后确认；前端成功事件仅触发状态查询。重复事件和重复点击保持幂等，取消和延迟可恢复。文件准备就绪且订单已支付后，才授予下载权限。

一笔订单解锁已预览成果，并额外赠送两个主图重做额度。用户主动重生成一张四风格图或一张九宫格图各消耗一个；完整两阶段重做消耗两个，只重做九宫格最多两次，二者共享余额、不叠加赠送。修改所选风格但尚未生成九宫格，不单独消耗额度。

重做权益按订单授予一次，不每日恢复；成功付款后可用，在订单文件有效期内使用。默认同一主体，可修正要求、风格或补充同主体照片；换成另一个人／动物属于新订单。用户成功收到但不满意的结果计入额度；上传校验失败和未获得有效结果的系统故障不扣用户额度，技术重试另受成本与次数上限约束。

已付费重做结果可直接查看高清和下载；保存版本，新的有效版本确认前保留旧版本，不因重做失败丢失已有成果。免费额度与付费重做分开，付费重做不再次收费，也不消耗当天免费额度。原订单退款后关闭剩余重做和新的下载权限。首版无需订阅或充值钱包。

### 免账号订单恢复

免注册适合当前一次性数字成果购买。购买前填写并确认交付邮箱；服务端记录匿名会话、订单和支付交易，不以可猜测的订单编号作为下载凭证。

- 同设备凭受保护的会话恢复任务与订单。
- 邮件提供带时效、可撤销的领取链接，用于换设备和找回文件。
- 主动找回订单时向原交付邮箱发送一次性链接／验证码，避免仅输入邮箱就暴露订单。
- 邮箱修改需证明拥有原订单或验证邮箱，不允许凭公开订单号改收件人。
- 恢复凭证仅授权对应订单，不引入跨产品账号或复用 Outline 授权短码。

### 切图与邮件

九宫格按实际尺寸切为九张，处理边界余数与安全留白，检查是否裁断主体；生成 ZIP。可在付款前完成私有预处理以验证可交付性，但公开下载和邮件只在服务端确认付款后开放。

邮件明确使用 Resend，由负责人指定且已经验证的发件地址发送，地址和密钥通过私有 `.env` 填写。邮件发送交付说明、受保护下载链接，并在大小允许时附完整 ZIP；附件过大时提供链接。邮件失败进入补发任务，不改变已支付状态、不要求再次付款。使用某个 From 地址不等于在该邮箱客户端自动保存一封“已发送”副本；若需要负责人邮箱留底，可另配归档收件人，默认留空。

Resend 官方当前说明邮件及日志保留 30 天，但它不能替代应用的私有文件存储，也不能让邮件中的过期链接继续有效。客户已保存的附件则不依赖服务器保留期。来源：[Resend 数据保留说明](https://resend.com/security)。

付费交付文件按付款成功起保留 30 天并到期清理；订单关联原照片仅保留到重做期限结束，未付款原图／预览默认建议 24 小时清理，期限可配置。重做不延长订单的原 30 天有效期。短期领取链接可在文件仍有效且验证订单后重新签发；发信成功不立即删除服务器文件，支持期限内的找回与补发。订单、付款和退款的最小审计记录与图片文件分开管理，不随图片到期删除。

**退款承诺：付款后 14 天内可申请退款。** 这是本产品拟承诺的规则；Paddle 官方并非对所有数字商品承诺一律 14 天无条件退款，其规则包含地区、下载使用及申请审核条件。不得把产品承诺误写成 Paddle 必然自动退款。首版提供联系／申请入口，核验订单后由后台处理；退款结果以确认的退款事件更新，取消新的下载、补发和重做权益，已经下载的文件无法远程收回。来源：[Paddle 退款政策](https://www.paddle.com/legal/refund-policy)。
