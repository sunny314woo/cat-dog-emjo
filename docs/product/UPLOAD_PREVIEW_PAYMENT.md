## 1. 本轮确定的产品流程

负责人明确的方向：

- 首选火山引擎 Seedream 5.0 Lite，由项目服务器调用；后续保留更换供应商的空间。
- 基础流程生成两张主图：一张风格预览图、一张九宫格表情图。九宫格中的九个单元不是九次独立出图。
- 未付款仅展示受保护的非高清九宫格，每个单元都要打码／加保护标记；付款后才可以查看高清图、下载裁切后的文件并获得邮件交付。
- 每用户每日免费一套，共两张主图（四风格 + 九宫格），不按 IP 计数；免账号身份识别方式待选择。全站费用预算另外设置。
- 每笔已付款订单赠送两个主图重做额度：完整重做一套或最多重做两次九宫格，共享额度。退款申请期 14 天，付费文件保留最多 30 天，Resend 邮件交付。

负责人确定至少上传一张、允许多张。当前提示词 v0.5 的图片合同为 1–2 张，因此首轮实现默认一张必填主照片 + 一张可选辅助照片，上限配置化。此前最多三张的建议保留为扩展选项，扩展时同步模板并实测。照片均表现同一个人或同一只动物，多张参考照片不等于生成多主体互动。

提示词库 v0.5 支持 9／18／27 张分页；本轮两张主图按基础 9 张包理解。首个完整闭环按九张验收；18／27 张包及其免费范围属于后续配置，不在本轮删除既有扩展规划。

## 2. 上传数量与参考图职责

### 首轮默认 1–2 张用户照片

| 照片 | 作用 | 建议上传指引 |
| --- | --- | --- |
| 必填主照片 | 主要身份、正脸、核心颜色与花纹 | 清楚、少遮挡、自然光；尽量只有一个目标 |
| 一张可选辅助照片 | 补充侧脸、耳形、发型、口鼻、身体花纹等 | 同一主体、外观接近当前状态；提供不同视角，避免只传重复照片 |

辅助图应补充主图信息；冲突、模糊、明显滤镜或不同年龄／外观状态的参考可能干扰生成。不能承诺“两张一定比一张更像”。建议先用相同主体、相同风格做单图／双图对照，比较身份辨识、结构、花纹与失败率，再决定是否默认推荐辅助图。

用户需确认多张图属于同一主体。照片中包含多人或多动物时，先指定一个目标，必要时裁剪；信息不足时要求更清晰的单主体照片。不能把自动判断作为身份核验保证。

### 大图与主体框选：可调整的首轮默认方案

参考照片的形状与输出的四格／九宫格形状是两件事。输出主图为正方形，不要求输入参考照片也必须为正方形；模型允许的输入宽高比也不等于产品最适合提供的裁切方式。

建议每张照片提供独立的确认界面：拖动照片或选框、缩放、确认目标范围，并可返回调整。合照先选定唯一目标，再裁剪；裁切不是多主体身份识别的替代，也不能恢复遮挡或模糊细节。

| 选框方案 | 优点 | 主要限制 |
| --- | --- | --- |
| 固定正方形 | 操作简单，适合正脸、头像与多数半身照片 | 可能裁掉长耳、长身体、手或尾巴，或保留过多无关背景 |
| 完全自由比例 | 适应不同主体与姿势 | 调整步骤更多，可能裁得过窄或过紧 |
| 默认正方形，可切换 3:4 竖框／4:3 横框 | 默认简单，同时照顾全身人物和横向动物 | 需在界面提供清楚的切换和完整性提示 |

当前建议采用第三种：默认正方形，必要时选竖框或横框；不把所有照片强制变成正方形。照片本身主体已经清晰、唯一且完整时，可以直接确认使用整图。框选保留核心特征和少量周边空间，避免切掉耳朵、发顶、口鼻与所需动作的身体范围；横竖切换与缩放均保持照片原比例，不拉伸人物或动物。

建议第一张优先脸部／半身，辅助图允许侧面或身体参考；不强制头部照片补出全身。手机上支持手势缩放和拖动，桌面提供拖动及缩放控件。自动推荐框可后续增加，首版不必为每张照片引入额外收费的识别调用。

超大原图还需独立做上传处理，选框本身不能控制文件体积。建议浏览器先纠正方向、裁切并缩小到最长边不超过 2048px，再上传；原始文件大小、像素上限、处理后体积与格式应另行设定并在服务端再次校验。这些是拟定值，需在还原质量和移动设备性能测试后冻结。用户必须能够查看实际发送的裁切预览，不在后台静默裁掉关键部位。

### 两阶段调用建议

1. **四风格预览：** 主照片 + 可选辅助照片 + 当前四种风格的提示词 → 一张四格主图。
2. **九宫格生成：** 同样的原照片 + 从四格中裁出的所选风格参考 + 当前九个动作的提示词 → 一张九宫格主图。

按当前最多两张用户照片，第二阶段最多三张模型参考图，另一张是系统产生的风格参考。必须明确用户确认后的照片负责身份、风格图仅负责画风；不能让生成预览替代原照片。

这是待实测的请求设计，并非已验证的身份一致性保证。传入多图时使用有序图片列表，在提示词中说明职责与优先级。

## 3. 火山技术与计费核对

核对日期：2026-10-02；限定火山方舟 Ark 的公开按量定价，不混用其他火山产品或第三方转售渠道的价格。

- Seedream 5.0 Lite 的多图生单图能力支持最多 14 张参考图。本产品没有必要把接口上限做成上传上限。
- 官方建议提示词不超过 300 个汉字或 600 个英文单词；这属于建议长度，并非此处定义的接口硬限制。长提示词可能让注意力分散、遗漏细节。
- 本项目应按当前主体、四种预览风格或一种最终风格、当前九个动作组装提示词，不直接发送整个提示词库。

来源：[火山方舟图片生成 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=en)。

当前公开定价：Seedream 5.0 Lite 输入参考图免费，输出图 ¥0.22／张，按实际生成的图片数量计费。因此在输出张数相同的前提下，增加一张参考照片不直接增加该项 API 费用；该价表也未列出按提示词长度额外收取的生图费用。

| 基础流程 | 输出主图数 | 基础生图费 |
| --- | --- | --- |
| 一张包含四风格的预览主图 | 1 | ¥0.22 |
| 一张包含九个表情的九宫格主图 | 1 | ¥0.22 |
| 合计 | 2 | **¥0.44** |

这是按两阶段各成功出图一次计算的预算值。切成四个风格参考或九张表情文件是本地后处理，不增加模型出图张数；若改为四张独立风格图或九张独立表情图，需按实际输出重新计算。成功出图但质量不合格的重试也产生新输出成本。

来源：[火山方舟模型价格](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)。上线前以实际账号、接入渠道与账单再次核对，价格不写死为产品长期承诺。

其他成本包括服务器、上传／下载流量、文件存储、邮件、支付渠道以及额外的分析模型或图像处理服务。是否启用这些收费服务需单独计入；本项目基础流程没有额外调用联网搜索的必要。

完整预览在成交前已产生生图成本。若每次免费体验成本为 ¥0.44、付费转化率为 p，仅这部分平均到每笔成交的成本就是 `0.44 / p`：例如 10% 转化率约 ¥4.40／成交，5% 约 ¥8.80／成交，尚未计入其他费用与重试。这是预算示例，不是转化率预测。

供应商切换应比较“每套合格且成功交付的结果成本”、身份还原、画风与延迟。保留服务端适配层和提示词版本；切换供应商前重新做多图、九宫格与质量验证。负责人提及的另一候选“Germany”名称待确认，不自行认定为 Gemini；OpenAI 为另一候选，目前未进行替代方案定价比较。

## 4. 高清原图与付费预览

建议采用如下流程，具体预览尺寸和保护强度待确认：

```text
上传原照片 → 生成四风格主图 → 用户选风格
  → 生成高清九宫格主图，私有保存
  → 服务端制作低清、逐格保护的预览 → 展示预览
  → 付款并由服务端确认
  → 开放同一份高清图 → 裁切／检查／打包 → 下载 + 邮件
```

**高清九宫格在付款前已经生成并保存在服务端，付款只解锁访问和交付。** 默认不在付款后重新绘制高清版，否则可能出现付费成果与预览不一致，也增加模型费用。若后续确需低清先生成、付款后超分或重新生成，应重新确定一致性、成本和失败处理方案。

保护必须由服务端处理图像像素，未付款客户端不能收到高清文件、原图 URL 或最终 ZIP。CSS 模糊、网页遮罩或叠加水印不能保护已经发给浏览器的高清图。

建议每一格都带覆盖主体部分的半透明水印，并降低预览分辨率，避免只在整图角落加一个可裁掉的标记。“打码”不宜将脸部和关键花纹遮到无法判断相似度：用户需看得出是否像、动作是否不同，才有购买依据。模糊程度、位置和尺寸应通过预览与购买意愿测试确定；此方案不能保证阻止截图或后续修复。

高清定义不能只写“高清”：需确定主图尺寸、裁切后有效尺寸、透明背景与边缘质量、格式、完整九宫格是否随 ZIP 提供，以及是否包含风格预览。大图裁为九格后单格分辨率约为主图边长的三分之一，不能直接把主图尺寸当成每张贴纸尺寸。

## 5. 免费预览预算与后续付费

### 最新决定：暂不做 IP 限制

此前提出过“每 IP 一次”，负责人在讨论共享网络误伤后已撤回，首版暂不实现该限制。不能因为旧草案有 IP 规则就据此阻止用户试用。

IP 不能稳定代表一个人；共享 IP 会导致限流误伤。相关技术依据：[Cloudflare 限流参数与 NAT 说明](https://developers.cloudflare.com/waf/rate-limiting-rules/parameters/)。最新个人额度为每日一套，免账号情况下按浏览器访客或验证邮箱识别尚待选择。不得默认为 IP，也不默认为强制注册。

### 建议以全站预算和任务上限控制费用

- **上传上限**控制图片处理资源，多参考图免费不等于服务器和流量无成本。
- **每次请求固定输出一张主图**，不让提示词触发额外组图；基础完整任务成功出图两次。
- **设有限重试**，例如每阶段最多一次自动重试；四次均成功出图时最多 ¥0.88 的基础生图成本。具体次数待确认，额外分析与处理服务另计。
- **设全站免费生图每日预算 B**。例如 B=¥20 时，零重试且每套 ¥0.44，最多约 45 套完整流程；这是预算示例，不是已确定额度。已有风格任务还需要完成九宫格，应提前预留后半程预算。
- **调用前服务端原子预留费用**，将进行中请求计入，预算不足时不启动新的免费任务；不能仅等账单事后发现超额。付费任务与免费试用预算分别管理，并保留各自上限。
- **到达上限提供清楚提示**，允许查看已有结果、付款解锁和领取已购文件；不得让免费预算耗尽破坏已付款交付。
- **限制任务并发，缓存已有结果**；是否加入验证码与个人生成额度，依据实际滥用情况再对齐。

每用户每日一套限制与全站费用上限同时存在。浏览器访客凭证可被清除或换设备绕过，因此不能只依赖个人额度控制全站支出。生图预算也不等于整个项目总费用上限，需另定存储、流量、邮件与其他收费服务的预算。

### 同一任务与失败恢复建议

- 每组确认的照片、四风格主图、所选风格和九宫格形成一个任务。幂等创建与预算预留避免重复点击意外启动多次。
- 同一任务可继续到九宫格；在风格阶段离开可以恢复，不重新调用第一阶段。
- 上传校验失败、模型未输出、系统处理失败，按同一任务恢复，提供次数有限的重试；不能承诺无限免费重试。
- 同主体换参考照片、改风格或要求重画属于新生成；已付款订单按两个主图重做额度扣减，完整两阶段消耗两个，仅九宫格消耗一个。换主体按新订单处理。
- 幂等查询、刷新和重新打开已有预览不重新调用模型。费用上限应包含失败阶段已经成功生成的图。

### 必须区分两种付款

| 付款场景 | 付款对应的权益 |
| --- | --- |
| 免费体验完成后，喜欢已有预览 | 解锁已有高清结果、裁切文件、下载和邮件，并赠送两个主图重做额度 |
| 想换照片／风格／主体重新生成，免费预算或后续个人额度不足 | 可设计为购买一套新生成与交付权益；是否先支付、购买次数及失败处理待确认 |

第二种场景需说明购买内容、重做余额和失败恢复；不得覆盖已付款订单赠送的两个主图重做权益。原订单的下载、补发和设备切换不再次收费。具体价格（USD 暂按 9.99／CN CNY 10）、Price ID、14 天退款承诺和 30 天文件保留以[主需求文档](../PROJECT_OVERVIEW.md)为准。
