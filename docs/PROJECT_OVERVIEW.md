## 1. 产品目标与首版范围

移动端优先的 H5：上传宝宝或宠物照片，选择主题和风格，服务端调用火山 Seedream 5.0 Lite 生成一张 3×3 九宫格母图，再由程序得到九张独立贴纸。

**匿名上传 → 选择主题与风格 → 生成九宫格 → 单张或全部揭晓 → 任选两张正式贴纸免费保存／分享 → 验证邮箱 → Paddle 解锁同一套九张 → 网页下载与 Resend 邮件交付。**

后续制作新照片、新主体、新风格、新主题或新的随机结果，都消耗一个新的 Pack。首次解锁已有结果不再调用模型，也不额外发一个新生成名额。

| 首版实施 | 后续规划，首版不开放 |
| --- | --- |
| 每次一个主体、一种风格、一个九表情子组 | 18／27 表情商品、完整系列一键生成 |
| 一张母图经程序得到九张贴纸 | 每张贴纸独立 AI 重画 |
| 盲盒揭晓、免费任选两张、完整包解锁 | 分享成功换权益、风格盲盒 |
| 邮箱验证码账户、Pack 余额、订单与任务 | 密码账户、会员、订阅、每日免费积分 |
| 单张保存／系统分享、完整 ZIP 与邮件 | 原生 App、小程序、聊天软件深度导入 |
| 首次解锁与 1／3／5 Pack 商品配置 | 作品云盘、永久下载、公共作品库 |

3／5 Packs 代表三次／五次独立生成权；每次仍只生成九张，不代表一次交付 27／45 张的大图。主题配置可保留未来 27 项和三个子组结构，首版仅开放已准备好的九项子组。

建议最小上线集合为“日常可爱 A”九项；上班族、社交回复可在其九项动作与样例验证后开放。不要求先设计完七个主题、189 个表情才能开发。

## 3. 上传、主题、风格与 Prompt

### 上传与裁切

首版一张照片、一个明确主体，宝宝／宠物分支。多人或多宠照片先指定唯一目标，必要时裁切；不做多人互动。上线物种按样例验证开放，不把模板覆盖范围当作已验证能力。

沿用可调整裁切建议：默认正方形，可选 3:4／4:3 或使用整图；拖动、缩放保持原比例，保留耳朵、头发、口鼻与必要身体。浏览器纠正方向并压缩，初始最长边 2048px；服务端再检查体积、像素与格式。具体上限待性能测试，用户能看到实际上传范围。

### 九项主题与四种风格

主题决定动作和文案，风格决定画法，二者独立。建议顺序为上传 → 主题 → 风格 → 生成。卡片使用固定真实样例，不把它们标为用户新照片的个性化结果。

保留十三种现有风格库；UI 展示四种经样例验证的风格，最终组合待选，不删除其他模板。

建议最小主题“日常可爱 A”沿原稿前九项：开心、超开心、撒娇、求抱抱、亲亲、比心、害羞、得意、期待。上线前检查各项差异及宝宝／猫／狗的适配。这是内容建议，不代表最终冻结。

每个表情统一定义 expression_id、theme_group、grid_group、cell_index、display_label、generation_semantic、visual_action、emotion、post_process_text、文字位置／样式、locale、active、prompt_version。cell_index 固定为当前九格内 1–9；未来主题内 1–27 顺序另设 theme_sequence，避免原稿中第 18 项与 cell_index=9 混用。

文字由程序叠加，模型只生成主体、动作和少量道具。“开会”“咖啡续命”需翻译成适合单主体小贴纸的动作，不直接拿文案当生图语义；宝宝主题采用年龄适宜道具，不表现宝宝饮用咖啡等行为。

### 现有 v0.5 模板需要适配

PET_STICKER_PROMPTS.md 保留为模块库，v0.1 附录不注入。实施前组装 V2.3 模板：

- 原照片锁定身份，直接注入所选一种风格和九项动作；不先生成个性化四风格图，不漏传原照片。
- 模型“无文字”保留，文字后处理独立执行。
- 原“无场景”与工作主题冲突，改为少量主题道具、透明外背景，保留单主体、安全区和不跨格。
- 原模板“逐张生成再拼图”、逐张补画和人工修图备选不用于本版。
- 保留风格、多图及分页库；本轮整理不覆盖已有 Prompt 改动。

## 4. 九宫格、正式文件与免费两张

正常成功路径生成一张九宫格母图。切图、背景移除、叠字、缩放和 ZIP 属于后处理，不是九次 AI 生图。技术重试可能增加输出成本，须单独预算，不能保证所有故障情况下也只有一次供应商调用。

后处理先得到九张质量合格的正式文件，私有保存，达到可交付状态后展示揭晓、允许收款。建议以每张有效清晰度至少达到 512×512 为试验目标；母图尺寸选模型实际支持值，单格像素约为母图边长三分之一，纯放大不能当真实高清。具体尺寸实测冻结。

透明背景是验收要求：检查真实 alpha、毛发、白色主体、半透明道具和文字边缘。PNG 格式或提示词写“透明”不等于成功。抠图方案需在目标机和不同风格上实测；不默认向低配置共享机部署重型本地模型，收费第三方另列成本与处理方。

揭晓只改变 UI，不调用模型或授予高清权限。用户可先开任意格，也可全部揭晓。first_reveal 表示先想看哪个，不等于最喜欢。

建议九张预览均完整呈现内容，使用服务端生成的低分辨率版本及轻量保护标记；其余七张正式文件不发给浏览器。保护强度待定，不依赖 CSS 遮罩保护已经传出的高清图。

免费两张与付费文件使用同一质量：无水印、合格透明背景、正式文字和裁切。建议用户点击“确认领取这两张”后由服务端原子锁定两个 cell_index；锁定前可改，锁定后可重复下载同两张，不能轮换领取九张。确认前明确提示，不绑定分享成功。

完整交付为九张独立透明 PNG、高清九宫格展示 PNG、ZIP 和邮件。两张免费文件包含在九张内，总数不是十一。展示九宫格可有单独背景，不替代透明文件。

## 5. 轻量账户、匿名体验与邀请

需要邮箱账户，管理身份、订单、Pack 余额、权益和退款账本，不建设密码注册、头像资料或作品库。

按新稿：匿名生成／免费两张 → 点击解锁 → Resend 验证码 → 自动创建／登录本项目账户 → 合并当前匿名任务 → Paddle 结账。已登录复购用户直接使用余额。验证码需过期、一次使用、尝试次数和发送限流。登录／交付不自动订阅推广。

新稿未明确免费体验频率。建议首次一次，不每日恢复；匿名资格、任务和两张领取记录在服务端，绑定邮箱后合并到稳定 user_id；已知付费账户后续按 Pack 执行。

清除数据或换设备可能得到新匿名身份，因此匿名流程无法严格保证“每个真实人只免费一次”。使用访问频率限制、短期风险信号、异常检测和全站预算；不做“一 IP 一次”的权益规则。若以后要求严格按账户限额，必须将邮箱验证前移，属于流程变更。

此前邀请一位成功付费新用户得一次重做的意向没有在 V2.3 中定义。建议暂不进入首版必交付清单，保留待确认，不认定为已取消。若保留，可参考 EnglishFlow 的稳定 user_id、一次归因、排除自邀及幂等奖励；其现有奖励是 Trial-only 的试用天数，不能直接照搬。此项目建议奖励一个独立 Generation Pack，在首次真实支付且退款观察期结束后发放，退款撤销未用奖励；单位、时机和上限待定。

### 首次解锁与新生成权分开

首次页强调完整包解锁，Create Another Pack 才进入 1／3／5 商店。首购优惠建议按验证账户一次，服务端原子判定；同任务重复点击恢复已有订单，多个并行结账的重复收款进入处理，不重复发权益。退款后是否恢复首购资格待定。

FIRST_PACK_UNLOCK 绑定具体 Generation，收款前检查资产存在且可交付。PACK_1／3／5 绑定账户和数量，支付确认只入账一次，创建任务时预占一个名额；webhook 不直接启动重复生图。

服务端验签，核验环境、交易状态、商品、price、金额／币种、订单与账户。前端支付成功只触发状态查询。事件唯一约束及 SQL 事务保证重复／乱序回调幂等、取消和刷新可恢复。

付款迟到而资源已删除时，不交空包、不悄悄重画：支付前检查最低剩余交付窗口，结账期间有限保留；仍迟到则退款／异常处理。

## 7. Pack 与任务状态、失败恢复

| 对象 | 建议状态与边界 |
| --- | --- |
| Generation | QUEUED → GENERATING → PROCESSING → READY；不可恢复错误 FAILED；资源清理 EXPIRED |
| 生成权益 | AVAILABLE → RESERVED → CONSUMED；最终技术失败返回 AVAILABLE，账本记录 RELEASED |
| 解锁订单 | PENDING → PAID → DELIVERED；退款 REFUNDED，邮件状态独立 |
| 邮件 | PENDING → SENT／FAILED，有限重试，不改变 Pack 消费 |

generation_id 与幂等键绑定匿名会话／user_id。同请求返回已有任务；同键不同配置拒绝。任务保存主题、九项、风格、模型与 Prompt 的版本快照。

付费任务原子预占一个 Pack，九张正式文件 READY 后消费。模型失败、模型原图下载失败、无法切割或后处理不可恢复失败释放。客户端断网／下载中断、邮件失败不释放已成功生成的 Pack，避免循环取得新生成权。

模型超时不能立刻认定没有成功，不并行重发。数据库持久任务与租约支持重启恢复。供应商不支持查询／幂等时不能承诺外部调用绝不重复；用有限重试和成本预留，保证用户账本只扣一次。

| 分类 | 处理 |
| --- | --- |
| 技术失败，无法获得可交付文件 | 有限恢复，最终失败释放 Pack |
| 身份／物种严重错误、主体缺失、主题动作明显不符 | 轻量反馈与必要退款，不自动赠新生成 |
| 不够可爱、想换风格／主题、再抽一次 | 新 Generation，消耗新 Pack |

反馈自动关联订单、任务和版本；资产仍在时关联输出，过期后明确已清理，可选补充说明。不为售后默认长期保留宝宝照片。

沿用此前付款后 14 天内可申请退款的产品意向，须与 V2.3 质量退款及 Bundle 规则一起冻结。建议按订单处理、不按坏格数部分退款；确认退款关闭未用名额及新的下载。已下载文件无法收回。退款期不等于图片保留期。

## 8. 保存、分享、邮件与生命周期

单张分享检查 navigator.canShare({files})，由用户点击触发系统分享；不支持时提供保存／打开图片回退。不保证直接导入微信、WhatsApp 或 iMessage 表情库，分享弹窗完成不能证明已发布到朋友圈。[浏览器文件分享能力](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/canShare)。

付款后网页先交付，Resend 优先附完整 ZIP，过大则提供短期链接。建议原始 ZIP 附件阈值 10MB，可配置；Base64 会放大体积。Resend 当前接口注明附件编码后每封最多 40MB，收件邮箱可能更严格。[Resend 邮件 API](https://resend.com/docs/api-reference/emails/send-email)。

不默认 BCC 运营邮箱，不把 From 地址或 Resend 日志当作品底册。验证码与交付邮件分开，发件人须已验证，密钥只放私有配置。

| 资产／记录 | 初始建议，可配置 |
| --- | --- |
| 原图及临时裁切副本 | 生成与必要处理完成后删除；失败／放弃最多 24 小时清理 |
| 免费 READY 结果 | READY 起 24 小时，显示到期时间 |
| 首购解锁结果 | 支付确认起 24 小时交付窗口；结账前核验并有限保留 |
| 付费 Pack 的新结果 | READY 起 24 小时交付窗口 |
| 签名下载链接 | 15 分钟且不超过资产寿命，文件仍在可重签 |
| 订单、Pack、最小任务／退款状态 | 独立于图片保留，期限待定义；不留图片和长期供应商 URL |
| 未用 Pack 余额 | 不随图片 TTL 删除；使用期限与退款规则另行冻结 |

不在发出一封邮件后立即删图。交付及有限重试期间保留，仍有最大 TTL；不误删进行中任务／待确认付款资源。过期无法恢复同一图，用户已下载文件及已收附件仍可使用。清理涵盖缩略图、ZIP、临时文件及日志／备份副本。

隐私目标：用户本人或监护人有权使用的照片，不公开、不营销、不作本产品训练集。调用火山是必要第三方处理，需在页面说明；供应商侧保留／训练条款与实际设置单独核验，服务器删图不代表所有第三方删除。

## 9. 独立后端与部署

按新稿：Python、FastAPI、MySQL、原生参数化 SQL、pymysql，禁止 ORM；常驻服务器、非 Serverless、本地优先。首版建议一个 API 进程和一个低并发 worker，以 MySQL 持久任务／邮件发件箱作为队列，不默认加 Redis 或 Celery。

HTTP 请求返回 task ID，网页轮询，不在请求中等待整个生图。同步 SQL／图像处理不阻塞异步请求循环；CPU、内存和并发受限，worker 初始并发建议 1，容量在目标机实测。SQL 事务保障 Pack、两张领取和 webhook。

最小数据对象：users、email_codes、anonymous_sessions、generations、assets、orders、payment_events、pack_ledger、mail_outbox、quality_reports、cost_reservations。实施时确定表结构，不用前端可改余额当账本。

建议目录，尚未迁移运行代码：

```text
web/                 H5 和公开固定示例
server/              FastAPI、worker、生成／支付／邮件适配器
config/              风格、九表情、商品配置，无密钥
docs/                当前需求、原稿和历史依据
assets/              可公开的既有示例
doubao/、UI/          仅本地参考，保持忽略
```

目标为 https://wisteriasoftware.uk/pet-stickers/；API 为 /pet-stickers/api，独立 webhook 为 /pet-stickers/api/webhooks/paddle。静态官网／产品介绍按新稿部署 Vercel，API、worker 和私有文件留在独立常驻后端。

同域名通过现有主站新增路径接入，不直接改根域名 DNS。Vercel 支持转发外部来源；部署前核验主站归属、上传体积／超时、cookie 路径和 HTTPS，订单／任务／私有下载禁止 CDN 缓存。[Vercel 外部转发](https://vercel.com/docs/routing/rewrites)。

Lightsail US$5／月是用户目标，不是本轮实测容量或当前套餐报价。复用 ssh wisteria 共享机器时，独立进程、端口、数据库／用户、配置与私有目录，限制资源；新购服务器属于另一个部署决定，不自动采购。

services/account-server 与 services/api-server 只读参考，不复用用户表、密钥或修改业务。不重启其他服务、不接管全局 /api、不改 Paddle 默认结账链接或其他 webhook。此前 SSH 只读检查不等于部署完成。

## 10. 费用、配置与指标

正常生成成本是一张母图输出，加后处理、服务器、存储／流量、邮件及支付费用。旧“两张主图／体验”的成本不用于本版。API 单价以实际接入点账单核验，多参考图或短 TTL 不等于成本上限。

免费预算启动前原子预留，计入排队、运行和技术重试；预算留空时禁止真实免费生成。预算耗尽不影响已有结果领取、付费 Pack 和订单交付。付费任务也设独立并发／重试限制。

免费生成平均成本 C、付款比例 p，则每笔成交分摊的免费生成成本近似 C/p，另加支付费等；这是预算模型，不是转化预测。

.env.example 是尚未由运行代码消费的目标合同。缺少真实配置不阻塞本地 mock，阻塞真实生成／收款／邮件；mock 不作为生产验收。

记录少量事件：生成开始／成功／失败、首次／全部揭晓、免费两张确认／下载／分享请求、解锁点击、邮箱验证、支付、Pack 预占／消费／释放、完整下载、发信、反馈和退款。字段为主题、风格、商品键、版本及 cell_index，不记录照片、验证码或支付敏感内容。分享只能反映网页观察到的调用结果。

先关注免费领取、解锁意向、首购／复购、Bundle 构成、退款和合格生成成本。27 系列完成率待系列开放后统计，不建庞大 Analytics 或收藏系统。
