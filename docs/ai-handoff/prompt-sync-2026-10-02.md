## 对比结论

| 项目 | 官网 v0.3 | 豆包文本 / HTML |
| --- | --- | --- |
| 主体范围 | 9 类动物及婴儿、幼儿、儿童、成人 | 旧文本有猫版、猫狗中英文版；HTML 仅猫狗 |
| 流程 | 照片分析 → 同姿势四风格 → 选风格 → 多动作九表情 → 检查导出 | 文本主要是直接九宫格；HTML 有四风格与九宫格两阶段 |
| 风格 | A 软萌 Q 版、B 简洁描边卡通、C 可爱半写实、D 绘本水彩 | HTML 是水彩蜡笔、萌系贴纸、3D 毛绒玩偶、简约线条；不能按位置直接对应 A/B/C/D |
| 风格约束 | 按所选风格变化比例、纹理和细节；不使用 3D | 旧文本的统一负面词禁止写实/细毛/3D，容易压制半写实和水彩；HTML 的毛绒风格明确允许 3D |
| 身份 | 原照片持续参与；可见特征优先，不猜品种、不编造未知部位 | 猫狗文本要求自动识别品种并严格锁定；部分不可见身体特征容易被猜测补齐 |
| 预览姿势 | 四格同姿势、角度、视线、表情，只比较画风 | HTML 已要求同姿势，但固定挥爪和笑脸，不是官网的温和中性预览 |
| 九宫格动作 | 依物种/年龄适配，表情与动作明显不同，保留自然结构 | 点赞、合十、星形瞳孔、翻白眼等旧动作可能改变爪子或五官结构 |
| 文字 | 全面禁止文字，包括睡觉的 Z | 三份文本和 HTML 都要求睡觉出现 z，同时另有禁止字母的约束，存在直接冲突 |
| 布局 | 隐形等大格，每格约 10% 安全区域，检查跨格后裁切 | 旧版强调填满、无留白，缺少安全区域，耳朵/爪子/爱心更容易裁断或跨格 |
| 背景 | 目标为真实 alpha；模型不支持时明确抠图并检查边缘 | 旧版先生成白底，再去白转透明；两条路线不能直接混成同一次请求 |

中英文猫狗文本也不是完全等价：英文版更明确规定三瓣肉垫、粉色爱心、蓝色泪滴和 z、黄色星星、黑色汗滴；中文版部分装饰未锁定这些颜色。这些装饰差异不是 v0.3 身份约束的核心。

## 豆包 HTML 中影响 Prompt 落地的缺口

以下均为静态源码核对，没有运行 API 验证：

1. `gridPrompt()` 描述参考图 A（身份）和 B（选中画风），但 `buildBody()` 实际只发送原照片 `state.photoDataURL`，未发送选中预览。当前只有文字风格描述起作用，不能声称锁定了参考图 B。应根据接口能力传两张图，或明确采用原照片 + 文字风格块的单图模式。
2. `callArk()` 会在参考图请求失败后尝试不带参考图。无原照片的结果不满足同一宠物的身份合同，后续接入应停止并报告错误，不能作为成功成品交付。
3. `sliceGrid()` 是 async 函数，`startGenerate()` 却使用 `blobs = sliceGrid(b)` 后直接调用 `blobs.map(...)`；该路径会对 Promise 调用 map，阻断后续处理。未来复用该实验代码时需先修正 await。
4. 旧版按 `Math.round(width / 3)` 直接切图，没有先校验可被 3 整除、主体完整、跨格或 alpha。v0.3 的程序校验仍需实现。

建议后续先落地猫狗分支与四种官网风格，验证原照片持续参与、风格区分、动作差异、安全裁切和透明边缘，再扩展物种与人物。本次没有合并新旧 Prompt，也没有修改豆包实现。

## Git 边界与凭据排除

当前结构是“目录嵌套，Git 仓库独立”：

```text
wisteria-suite/.git                     外层大仓库
wisteria-suite/apps/emjo/.git           独立 cat-dog-emjo 仓库
```

- 内层 `origin` 指向 `cat-dog-emjo`；现有官网文件与 Prompt 继承远程跟踪记录，无需重新创建初始提交。
- 外层 `.git/info/exclude` 已加入 `/apps/emjo/`。这只影响本机，不修改外层仓库的受跟踪文件；换机器需重新设置。不要从外层 `git add apps/emjo`，否则容易误添加为 Git 链接。
- 本次没有创建 submodule。当前不需要让大仓库记录这个独立项目的提交指针。
- 内层 `.gitignore` 整体排除 `/doubao/`、`/UI/`、`/.local-backups/`、真实 `.env` 和常见凭据文件名。不要强制添加这些文件。
- 对远程历史中的 19 个文件 blob 做了本地已知 key 匹配及常见 token/私钥特征扫描，未发现匹配；这是有限的静态检查，不是完整凭据审计。
- `.env.example` 的敏感字段已检查为空或占位符。
- Git 排除不等于网站部署排除；部署只选官网公开文件与 `assets/`，不把本地参考目录、环境文件或备份目录复制到公开根目录。
